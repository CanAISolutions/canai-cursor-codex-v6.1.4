# 🛠 Prompt Revisions & Suggestions

This folder contains suggested improvements, A/B test candidates, and experimental prompt versions.  
Nothing in this folder is routed live — it's used by devs and AI copilots for evolution and QA.

## File Types

- `*.suggestion.txt`: Human/AI-generated rewrite instructions based on low score or feedback
- `*.experimental.prompt`: Draft `.prompt` files not yet routed to `/gpt-templates/`
- `scorelog-*.json`: Prompt performance snapshots (optional)

## Workflow

1. Suggestions are generated by `/tools/tunePromptFromFeedback.ts`
2. If adopted, a `.v2.prompt` is created here for review
3. If approved, the `.v2.prompt` is promoted to `/gpt-templates/`
4. Prompt versions in `/gpt-templates/` are tracked via `/prompt-versions/`

> This folder is the R&D layer of the CanAI prompt system.
