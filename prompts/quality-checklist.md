# AI Prompt Quality Checklist

## Pre-Query Validation

### **Context Completeness**
- [ ] Exact code snippet included with proper formatting
- [ ] File path and line numbers specified clearly
- [ ] Environment/tech stack mentioned (Node.js, React, Python, etc.)
- [ ] Clear, specific goal stated in ≤10 words
- [ ] Constraints explicitly defined and reasonable

### **Emotional Sovereignty Preparation**
- [ ] User expertise acknowledged in request
- [ ] Existing good patterns celebrated
- [ ] Intent honors user vision and autonomy
- [ ] Sacred Reversal Test considered: "Would this empower the user?"

### **Test-First Truth Standards**
- [ ] Success criteria clearly defined
- [ ] Validation approach considered
- [ ] Evidence requirements specified
- [ ] Fallback plans included if needed

## Post-Response Validation

### **Format Compliance**
- [ ] Intent echoed in ≤10 words at start
- [ ] Changes cited as `line_start:line_end:filename`
- [ ] Only changed code shown with `// ... existing code ...` markers
- [ ] Context respected and preserved
- [ ] No hallucinated or unnecessary content

### **Emotional Intelligence Assessment**
- [ ] **Recognition**: Response acknowledges user expertise
- [ ] **Respect**: Honors existing code patterns and vision
- [ ] **Empowerment**: Makes user feel more capable
- [ ] **Partnership**: Feels like trusted advisor, not judgment
- [ ] **Trust Transparency**: Clear communication of reasoning

### **Technical Quality Gates**
- [ ] Minimal, surgical changes only
- [ ] Existing signatures and props preserved
- [ ] Architecture patterns maintained
- [ ] Error handling appropriately considered
- [ ] Performance implications addressed

### **Sacred Reversal Test Validation**
- [ ] Response would feel supportive if roles were reversed
- [ ] User would feel seen and understood
- [ ] User would feel more confident after interaction
- [ ] User would trust the AI with future challenges

## Success Metrics

### **Immediate Success Indicators**
- [ ] **First-try Success**: Works correctly without revision
- [ ] **Clarification Rate**: ≤1 follow-up question needed
- [ ] **Hallucination Check**: Zero fabricated or irrelevant content
- [ ] **Time Saved**: Measurable efficiency improvement
- [ ] **Trust Score**: 4.2+ maintained

### **Long-term Quality Metrics**
- [ ] **Pattern Learning**: AI remembers user preferences
- [ ] **Empowerment Growth**: User feels increasingly capable
- [ ] **Partnership Strengthening**: Trust relationship deepens
- [ ] **Competence Amplification**: User skills enhanced, not replaced

## Escalation Triggers

### **Quality Issues**
- **Response doesn't match format requirements** → Retry with template
- **Hallucinations detected** → Flag for improvement
- **User expertise not acknowledged** → Emotional sovereignty violation
- **Sacred Reversal Test failed** → Trust transparency review

### **Success Rate Monitoring**
- **First-try success <90%** → Template optimization needed
- **Clarification requests >10%** → Context gathering improvement
- **Trust score <4.2** → Emotional sovereignty intervention
- **User empowerment declining** → Partnership repair protocol

## Implementation Notes

### **For Development Teams**
- Use this checklist for all AI-assisted code changes
- Document quality metrics in PR descriptions
- Share successful patterns across team
- Escalate persistent quality issues

### **For Individual Developers**
- Run through checklist before and after AI interactions
- Track personal success metrics over time
- Note patterns that work well for your coding style
- Build trust through consistent quality validation

## Continuous Improvement

### **Weekly Reviews**
- Analyze quality metrics and trends
- Identify successful patterns to amplify
- Address recurring quality issues
- Update templates based on learnings

### **Monthly Optimization**
- Refine templates and constraints
- Enhance emotional intelligence patterns
- Strengthen test-first truth integration
- Deepen sacred reversal test compliance

**Remember**: This checklist serves not just technical excellence, but the sacred trust users place in AI to honor their dreams and amplify their potential.
