## VERIFICATION-FIRST APPROACH

As of 2025-05-28, we have adopted a strict verification-first approach:

1. **Core Principle**: Nothing is considered complete without direct verification evidence
2. **Verification Hierarchy**:
   - Direct Test Evidence (Highest)
   - Code Inspection Evidence
   - Runtime Verification
   - Documentation Evidence (Lowest - never sufficient alone)
3. **Evidence Requirements**:
   - All status claims require direct verification evidence
   - All verification includes timestamps and methodology
   - All evidence stored in `/docs/verification-evidence/`
   - Zero assumptions about file existence implying functionality

See `docs/VERIFICATION-FIRST-PROTOCOL.md` for complete verification standards.
