## 🤖 AI Copilot Empowerment Guide

**When building with AI copilots (e.g., Cursor):**

| Rule | Application |
|:-----|:------------|
| Annotate Intent | Always comment on *what*, *why*, and *how* when writing any new module. |
| Modularize Outputs | No monolithic files — always functions, helpers, modules. |
| Embed Validation Contracts | Any function dealing with external inputs must define explicit expected types. |
| Codify Evolution Points | When future extensibility is expected, leave a `// TODO: Extend for [X]` marker with clear context. |
| Maintain Readability | Variables, function names, and folders must be immediately comprehensible without explanation. |
| Protect Dream-State UX | Never surface raw errors, panic exceptions, or broken emotional flows to users or internal ops. |
| Write Snapshot-Safe | Every commit should leave the repository in a *safe-to-snapshot* Cursor-ready state. |
| Update Readmes Immediately | New files = New READMEs or updated section in existing READMEs within the same PR. |
