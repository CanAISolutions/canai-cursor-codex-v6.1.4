# 🎨 CanAI Brand Identity

---

## 🧠 Brand Essence

- **Mission**: Empower small businesses with strategic clarity, instantly.
- **Tagline**: Empowerment Through Ease.
- **Tone**: Emotionally intelligent, professional, empowering, human.
- **Feel**: Simple. Strategic. Supportive. Scalable.

---

## 🔤 Voice & Messaging

### Guidelines:
- Speak like a strategist, not a robot
- Use markdown in outputs: `# Heading`, `**Bold**`, `- Bullets`
- Avoid generic tone: never say "output complete"
- Use phrases like:
  - “Here’s your strategy.”
  - “Launch-ready.”
  - “You’re set up for success.”

---

## 🖼 Visual Design Rules

| Element         | Rule                                                   |
|-----------------|--------------------------------------------------------|
| Font            | Inter (Google Font, all weights)                       |
| Corner Radius   | Rounded-2xl (12px–16px)                                |
| Shadows         | Soft (`shadow-md`) — never harsh or deep               |
| Layouts         | Grid-based, centered, with ample breathing room        |
| Cards           | White bg, soft border, brand blue headline             |

## ✅ Output Style Examples

- `# Business Plan Blueprint`  
- `## Executive Summary`  
- `**Clarity** and action over fluff.`

All prompt outputs should:
- Begin with a meaningful heading
- Be easy to skim
- Include at least one **sectioned format**
