## 🔧 How to Use the Cultural Intelligence System

### **1. Cultural Analysis**
```javascript
// Analyze content for cultural context
fetch('http://localhost:3000/api/cultural-analysis', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    content: 'I humbly request your guidance and respect your expertise in this matter.',
    sessionId: 'user_session_123'
  })
})
.then(response => response.json())
.then(data => {
  console.log('Detected Region:', data.region);
  console.log('Confidence:', data.confidence);
  console.log('Formality:', data.formality);
  console.log('Directness:', data.directness);
});
```

### **2. Cross-Cultural Adaptation**
```javascript
// Adapt content across cultural boundaries
fetch('http://localhost:3000/api/cross-cultural-adapt', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    content: 'I appreciate your direct feedback on this issue.',
    sourceRegion: 'north_america',
    targetRegion: 'east_asia',
    sessionId: 'user_session_123'
  })
})
.then(response => response.json())
.then(data => {
  console.log('Adapted Content:', data.adaptedContent);
  console.log('Preservation Score:', data.preservationScore);
  console.log('Formality Adjustment:', data.formalityChange);
  console.log('Directness Adjustment:', data.directnessChange);
});
```

### **3. Emotional Intensity Calibration**
```javascript
// Calibrate emotional intensity across cultures
fetch('http://localhost:3000/api/calibrate-intensity', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    emotion: 'enthusiasm',
    intensity: 0.9,
    sourceRegion: 'latin_america',
    targetRegion: 'east_asia',
    sessionId: 'user_session_123'
  })
})
.then(response => response.json())
.then(data => {
  console.log('Calibrated Intensity:', data.calibratedIntensity);
  console.log('Calibration Factor:', data.calibrationFactor);
  console.log('Cultural Context:', data.culturalContext);
});
```
