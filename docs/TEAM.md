# 🤝 CanAI Team Values & Roles

This document outlines who we are, how we work, and what we protect — so that CanAI scales with integrity, clarity, and purpose.

---

## 🧠 Core Philosophy

We build systems that think and feel.  
Every prompt is a product.  
Every output is a customer experience.  
Every improvement is a gift to our future.

---

## 💡 Values We Protect

| Value               | Description                                                        |
|---------------------|---------------------------------------------------------------------|
| Clarity             | No jargon. No guesswork. Simplicity is sacred.                      |
| Empathy             | Every output should support a human, not just solve a problem.      |
| Execution           | Ideas don’t win. Systems that ship and improve do.                  |
| Ownership           | We don’t outsource responsibility — we own the result.              |
| Trust               | We never break it. Not with users. Not with each other.             |

---

## 👥 Core Roles

| Role            | Owner           | Responsibilities                                 |
|------------------|------------------|--------------------------------------------------|
| Product Vision   | [Founder Name]   | Drives strategy, system clarity, and user delight |
| Dev & Automation | You / Cursor     | Maintains logic, prompts, backend, automations   |
| Brand + UX       | Systemwide       | Enforced via `/brand`, `.cursorrules`, and prompts |
| Data & Learning  | Make + Airtable  | Track usage, feedback, and system evolution      |

---

## 🤖 AI as a Teammate

- Cursor is our development copilot
- GPT-4o is our strategist in code
- Prompts are our playbooks
- Fallbacks, scores, logs = self-correction and learning

---

## 🔄 Evolution Mindset

We do not build static tools.  
We build a living system —  
One that refines itself from every click, feedback, and prompt delivered.

---

> CanAI is not just a product.  
> It’s a philosophy, a standard, and a system that’s built to outlast its creators.
