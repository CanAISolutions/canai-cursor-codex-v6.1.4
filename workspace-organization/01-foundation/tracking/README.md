## 🛠️ **Production Setup Instructions**

### **1. Database Setup (Production)**
```bash
# Deploy production schema to Supabase Pro
psql -h your-supabase-host -U postgres -d postgres -f production-schema-deployment.sql

# Verify deployment
node validate-deployment.ts --test-schema
```

### **2. Environment Configuration (Production)**
```bash
# Required environment variables
export SUPABASE_URL="your-supabase-url"
export SUPABASE_SERVICE_KEY="your-service-key"
export AWS_ACCESS_KEY_ID="your-aws-key"
export AWS_SECRET_ACCESS_KEY="your-aws-secret"
export AWS_REGION="us-east-1"
export IMPLEMENTATION_START_DATE="2025-01-27"
```

### **3. Production Services Setup**
```bash
# Deploy BERT Lambda function
node bert-lambda-deployment.ts

# Initialize metrics integration
node production-metrics-integration.ts

# Validate all services
node validate-deployment.ts --full-validation
```

### **4. CLI Installation (Production)**
```bash
# Install minimal dependencies
npm install @supabase/supabase-js

# Make CLI executable
chmod +x production-cli-dashboard.js

# Run production dashboard
./production-cli-dashboard.js
```
