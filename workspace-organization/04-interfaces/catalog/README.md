# CANAI Interface Catalog

This directory contains interface catalog files that document all system interfaces for API integration and automation.

## Current Status

We've identified a critical issue in which the CANAI-INTERFACE-CATALOG-V2.json file does not include complete definitions for all interfaces from the original CANAI-INTERFACE-CATALOG.json file, despite referencing them in relationships and usage patterns. We need to create a definitive catalog that includes ALL interfaces with 100% accurate definitions.

## Files in this Directory

- **CANAI-INTERFACE-CATALOG.json** - Original interface catalog with 38 interfaces
- **CANAI-INTERFACE-CATALOG-V2.json** - Expanded catalog with 27 new interfaces (but missing some original interface definitions)
- **DEFINITIVE-INTERFACE-CATALOG-PROMPT.md** - Detailed prompt for creating a definitive catalog
- **verify-interfaces.sh** - Shell script to verify interface definitions against code
- **generate-definitive-catalog.ts** - TypeScript utility to generate a merged catalog
- **README.md** - This file

## Instructions for Creating the Definitive Catalog

### Method 1: Manual Verification (Most Accurate)

1. Read the detailed instructions in `DEFINITIVE-INTERFACE-CATALOG-PROMPT.md`
2. Use the verification shell script to identify issues:
   ```
   chmod +x verify-interfaces.sh
   ./verify-interfaces.sh
   ```
3. Review the `verification-results.md` file generated by the script
4. Manually verify each interface against actual code implementations
5. Create a new JSON file called `CANAI-INTERFACE-CATALOG-DEFINITIVE.json` combining all interfaces

### Method 2: Automated Generation + Manual Verification

1. Install required dependencies:
   ```
   npm install --save-dev typescript @types/node
   ```
2. Run the TypeScript generator utility:
   ```
   npx ts-node generate-definitive-catalog.ts
   ```
3. Review the generated `CANAI-INTERFACE-CATALOG-DEFINITIVE.json` file
4. Review the `verification-report.md` file for issues
5. Manually verify and fix any interfaces marked as needing verification

## Verification Checklist

Ensure the final catalog meets these requirements:

- [ ] Contains all 38 interfaces from the original catalog with COMPLETE definitions
- [ ] Contains all 27 new interfaces from the V2 catalog with COMPLETE definitions
- [ ] Every interface is verified against actual code implementation
- [ ] No interfaces are missing or incomplete
- [ ] Accurate relationships between interfaces
- [ ] Complete webhook integration mapping
- [ ] Consistent structure and formatting
- [ ] 100% field-level accuracy compared to code
- [ ] Categories correctly assigned
- [ ] Integration priorities accurately reflected

## Important Notes

1. **Code Verification**: Always verify interface definitions against actual TypeScript code implementations, not just catalog descriptions.

2. **Missing Interfaces**: The V2 catalog appears to be missing complete definitions for several key interfaces from the original catalog, including `GoldmineOutput` and others.

3. **Webhook Integration**: The definitive catalog must include complete webhook integration mappings for ALL interfaces to support API integration.

4. **Trust-First Truth**: This catalog will be used for critical API integration and automation. Its accuracy directly impacts system reliability and emotional sovereignty. Thorough verification is ESSENTIAL.
