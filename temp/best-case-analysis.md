## 🎯 **STRATEGIC RECOMMENDATION**

### **The Universal Core (5 Fields)**
**Every prompt should capture these for superior output**:
1. **`industry`** - Market context and expertise
2. **`targetAudience`** - Who this serves  
3. **`primaryGoal`** - What success looks like
4. **`businessContext`** - Company size/type/stage
5. **`qualityLevel`** - Basic/Professional/Premium expectation

### **Tiered Enhancement Strategy**:

**Premium Tier (Business Plan, AI Blueprint, Site Audit)**:
- Core 5 + 4-5 specialized fields = 9-10 total

**Professional Tier (All others)**:
- Core 5 + 2-3 specialized fields = 7-8 total

**This approach**:
- ✅ Captures high-value data for superior outputs
- ✅ Reduces complexity burden on customers
- ✅ Maintains differentiation against basic AI
- ✅ Simplifies database architecture
- ✅ Enables smart defaults and inference
