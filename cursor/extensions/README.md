# Cursor Usage Guardian

## Overview
Tracks real-time token usage and estimated API costs inside Cursor.

## Features
- Tracks tokens used per session
- Estimates API costs based on provider
- Breaks out usage by provider (e.g., OpenAI, DeepSeek)
- Tags by CanAI prompt type (`business_plan`, `social_content`, etc.)
- Provides a sidebar dashboard view

## Setup
1. Install the extension in Cursor.
2. (Optional) Customize `costEstimator.ts` for specific API pricing if needed.

## Future Enhancements
- Daily/weekly aggregations
- Usage alerts
- Auto-optimization recommendations
