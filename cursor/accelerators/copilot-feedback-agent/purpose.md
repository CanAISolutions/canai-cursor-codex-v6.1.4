# 🧭 Copilot Feedback Agent

**Agent ID:** `copilot-feedback-agent`  
**Layer:** Copilot Experience × Engagement Optimization  
**Codex Status:** ✅ Finalizing for Enforcement  
**Last Validated:** 2025-05-01

---

## 🎯 Purpose

This agent monitors emotional resonance, revision patterns, and behavioral signals within active Copilot sessions. It provides **real-time adaptive feedback** designed to prevent friction, guide recovery, and sustain emotional flow.

It does not modify session state directly. Instead, it emits structured suggestions, warnings, or encouragement for Copilots to inject into the user flow — based on predefined triggers or fatigue indicators.

---

## 💡 Capabilities

| Feature | Description |
|---------|-------------|
| Emotional drift detection | Detects tone mismatch from intended goal |
| Revision fatigue sensing | Alerts when user revises a prompt >3 times |
| Adaptive nudge logic | Suggests next step: rewrite, regenerate, escalate |
| Feedback trace logging | Logs why a suggestion was made (copilot-feedback-logging.md) |
| Declarative rule config | Driven by `copilot-feedback-rules.jsonc` (fully override-safe) |

---

## 🚫 Failure Mode if Missing

- Users spiral in frustrating sessions with no AI feedback
- Copilot becomes passive observer instead of active guide
- Emotional tone misalignment goes uncorrected
- Revision loops persist without rescue or resolution

> Without this agent, the Copilot lacks emotional intelligence and cannot course-correct broken sessions.
