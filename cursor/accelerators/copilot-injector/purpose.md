## 🎯 Purpose

Inject emotionally intelligent Copilot feedback into prompt sessions when outputs stall, misfire, or lose clarity.

This module safeguards session quality by:
- Detecting tone drift, clarity breakdowns, or revision fatigue
- Suggesting small but strategic nudges to help the user realign
- Reinforcing emotional resonance with respectful Copilot interventions

Its job is to keep sessions **clear, emotionally connected, and conversion-viable** — without being intrusive or robotic.

---

## 💡 Key Capabilities

| Capability | Description |
|------------|-------------|
| Low-score detection | Identifies weak outputs based on scoring thresholds |
| Revision loop sensing | Detects >6 edits without meaningful change |
| Emotion flatline alert | Flags emotionally dull content |
| Injection guardrails | Max 2 Copilot nudges per session |
| Defensive co-authoring | Never overwrites user input or breaks flow |
| Fully declarative config | All triggers defined in `copilot-trigger-rules.jsonc` |

---

## 🚫 Failure Mode if Absent

- Sessions may degrade without rescue
- Copilot becomes reactive, not proactive
- Users may revise in circles, feeling unsupported
- Emotional trust is eroded silently

> “This module protects momentum. It speaks up when users won’t — to keep trust alive.”
