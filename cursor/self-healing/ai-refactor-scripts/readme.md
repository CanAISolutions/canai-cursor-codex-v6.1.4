# 🧠 ai-refactor-scripts/

> Autonomous refinement infrastructure for intelligent, emotionally-safe system evolution.

---

## 📌 Purpose

This folder contains all logic and orchestration systems responsible for detecting, evaluating, and refining prompt or output quality. It is the core loop for ensuring CanAI improves over time without degrading emotional resonance, semantic clarity, or structural integrity.

---

## 🧱 Responsibilities

- Detect output drift (emotional, semantic, structural)
- Replay and compare historical prompt sessions
- Quantify quality of system-generated changes
- Suggest targeted prompt improvements
- Codify recursive, safe, intelligent revision loops
- Maintain audit safety and dream-state emotional fidelity

---

## 📂 Key Modules

| File | Purpose |
|------|---------|
| `smart-revision-loop.md` | Codex-governed loop architecture for recursive improvement |
| `output-delta-analyzer.ts` | Compares old vs new outputs and detects drift |
| `promptReplay.ts` | Replays historical prompt inputs to detect divergence |
| `selfRefineScore.ts` | Scores how much an output improved, regressed, or stayed neutral |
| `promptFixSuggestor.ts` | Suggests targeted next-step fixes for degraded prompts |
