# CanAI Agents

## Overview
This directory contains the core agents that power CanAI's emotional intelligence, codex compliance, and self-healing capabilities.

## Agent Categories

### 1. Core Agents
- `input-validator.ts`: Validates input quality and emotional resonance
- `qa-scorer.ts`: Scores output quality and emotional alignment
- `empathy-validator.ts`: Ensures empathetic and emotionally safe outputs
- `prompt-logs.ts`: Manages prompt logging and emotional traceability

### 2. Emotional Intelligence Agents
- `emotionalIntegrityAgent.ts`: Maintains emotional integrity across outputs
- `emotionalStabilizer.ts`: Stabilizes emotional tone and resonance
- `earlyDriftDetectors.ts`: Detects emotional drift and tone misalignment

### 3. Codex Compliance Agents
- `alignmentAuditor.ts`: Ensures codex compliance and alignment
- `codexExpansionAgent.ts`: Manages codex expansion and evolution
- `modularityEnforcer.ts`: Enforces modularity and component isolation

### 4. Strategic Agents
- `opportunityRadar.ts`: Identifies improvement opportunities
- `recursive-thinker.ts`: Provides recursive analysis and improvement
- `output-evaluator.ts`: Evaluates output quality and emotional resonance
