# 📖 Context Injection Glossary

> Master reference for system concepts, Codex terminology, and operational framing.  
> Use during audits, prompt evolution, or Copilot augmentation to preserve semantic stability.

---

### Core Concepts

- **Dream-State Alignment:**  
  Outputs evoke clarity, empowerment, emotional safety, and operational trust.

- **Codex Directive:**  
  Non-negotiable operating rule that governs modularity, UX, audits, and evolution.

- **Drift:**  
  Silent, unintended deviation from emotional resonance, modularity, UX tone, or Codex principles.

- **Silent Decay:**  
  Gradual degradation of system quality, modular clarity, or UX consistency without explicit failure.

- **Modular Cohesion:**  
  Degree to which a folder or file strictly fulfills a clear, isolated mission without sprawl.

- **Emotional Resonance Score:**  
  Quantified emotional impact of an output, measuring clarity, empowerment, tone, and user trust.

- **Revision Loop:**  
  Structured, Codex-governed cycle of prompt/output self-improvement based on audits and refine scores.

- **Edge Case:**  
  Rare but known input/output scenario where UX, modularity, or emotional experience could degrade.

- **Self-Healing Trigger:**  
  Automated mechanism that detects drift or decay and initiates a corrective response without human intervention.

- **Copilot Augmentation:**  
  Design pattern where outputs, audits, and structures are modular and reasoning-traceable for LLM co-builders.

- **Snapshot-Safety:**  
  Ability for a file, function, or prompt to be copied, audited, and evolved without hidden dependencies or assumptions.

---

### Usage Notes

- All agents, audits, and prompts must maintain glossary semantic consistency.
- Terms evolve only via Codex Directive expansion and version-controlled updates.
- Copilots must validate glossary injection before autonomous refactor or audit operations.
