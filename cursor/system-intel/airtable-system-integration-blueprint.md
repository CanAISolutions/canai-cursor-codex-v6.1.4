## 02 — CORE STRUCTURE: MEMORY, EMOTION, MOTION

### Canonical Tables
- `PromptLogs`: Tracks intent, inputs, fallbacks.*  
- `FeedbackLogs`: Captures resonance, micro-emotions.*  
- `SessionAnalytics`: Maps momentum, friction, goals.*  
- `ReferralTriggers`: Drives trust flows, viral loops.*  
- `DeliveryCostLogs`: Monitors margins, costs.*  
- `UserContext`: Encodes cultural, cognitive, emotional traits.*

_*Tables*: Sharded across 5 global zones, synced via CRDTs.

### Required Fields
- `recordId` (ULID, globally unique)  
- `createdAt`, `updatedAt` (SmartTimestamp pair)  
- `contextVector` (e.g., `["novice", "bold", "EMEA"]`)  
- `clarityIndex` (0–10, context-weighted)  
- `resonanceScore` (0.0–1.0, emotional impact)  
- `momentumScore` (progress velocity)  
- `trustFallbackUsed` (boolean)  
- `deliveryCost` (float, webhook-computed)  
- `emotionTensor` (e.g., `{hope: 0.7, doubt: 0.2}`)*  
- `emotionTrendScore` (emotional trajectory)  
- `CanAIImpactScore` (KPI: clarity, trust, momentum, joy)*  
- `emotionChurnRisk` (dropout prediction)*  
- `cohortEmotionModel` (segment trends)

_*emotionTensor*: Derived from NLP, user reports, session signals; ≥90% alignment with human annotations.  
_*CanAIImpactScore*: `0.4*clarityIndex + 0.3*resonanceScore + 0.2*momentumScore + 0.1*joyFactor`.  
_*emotionChurnRisk*: Logistic regression on `emotionTrendScore` decay.

### Field Metadata
- `emotionalRole`: `clarity`, `trust`, `momentum`, `pride`, `joy`  
- `dataSensitivity`: `pii`, `internal`, `public`  
- `contextScope`: `session`, `user`, `global`
