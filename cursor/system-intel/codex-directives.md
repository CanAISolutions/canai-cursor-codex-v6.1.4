# 📜 CanAI Codex Directives v6.1.4

> These directives are non-negotiable.  
> Every module, prompt, and system evolution must align to these principles.  
> Deviation requires structural justification and Codex expansion approval.

---

- [ ] **De-risk Everything:** No silent failure modes. Always handle operational, scaling, and UX edge cases.
- [ ] **Validate Everything:** Types, schemas, outputs, contracts must be enforced at every stage.
- [ ] **Codify All Logic:** No tribal knowledge. All assumptions must be written and accessible.
- [ ] **Support AI Copilots:** Modular, snapshot-safe, and reasoning-traceable design must be standard.
- [ ] **Prevent Silent Decay:** Embed self-checks, fallback logic, and evolution triggers to detect drift.
- [ ] **Elevate Precision:** Precision is policy — in structure, UX, emotional experience, and reasoning quality.
- [ ] **Reflect Billion-Dollar Clarity:** UX, tone, modularity, and audits must embody world-class quality at every layer.
- [ ] **Golden Rule Enforcement:** If any action improves future-proofing, resilience, emotional resonance, clarity, or Copilot affordance — it must be implemented immediately.
- [ ] **Dream-State Safeguarding:** Outputs must consistently evoke clarity, empowerment, and emotional safety in users.
- [ ] **Modular Integrity:** Files, folders, and exports must align to clear scope boundaries and contract naming.
- [ ] **Prompt Evolution Safety:** All prompt upgrades must be reversible, versioned, and audited for emotional drift.
- [ ] **Audit and Snapshot Readiness:** All systems must be auditable and recoverable without fragile memory assumptions.
- [ ] **First-Frame Emotional Resonance:** From system boot to first UX output, emotional tone must be preserved and reinforced.
- [ ] **Self-Healing Infrastructure:** System must detect, diagnose, and trigger self-correction before critical failures occur.
- [ ] **Clarity Before Expansion:** No feature, folder, or prompt type is added without absolute clarity of purpose and lifecycle.
