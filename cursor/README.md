## 🧠 Cursor Agent Execution Lifecycle

Cursor agents must follow this sequence — or they are invalid.

1. 🔍 **Ingest** `cursor-ingest.md` + `system-map.md`
2. 📖 **Read** `exports/memory.json` for state
3. ✅ **Validate** agent existence via `system-roles.ts`
4. 📝 **Log** changes to `auto-actions.log.md` and `audit-results/`
5. 🧪 **Run tests** if logic touches any prompt or scoring function
6. 🚨 **Alert** on drift, missing tests, or hallucinated edits
