# Log Expectation – cursor/contracts/

All contract changes, additions, or removals must be logged in:
- /cursor/auto-actions.log.md (with phase, contract, and rationale)
- /cursor/system-intel/audit-reflections.md (if contract impacts audit or system behavior)

Required log fields:
- contract name
- action (add, update, remove)
- rationale
- Codex phase
- affected modules
