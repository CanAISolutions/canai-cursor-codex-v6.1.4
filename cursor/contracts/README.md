# cursor/contracts

This directory contains all formal TypeScript contracts and placeholder types for plugins and services in CanAI.

- All plugin/service interfaces must be declared here (e.g., TPluginMeta, TServiceContract).
- Shared types may be migrated or aliased from /cursor/types/ with audit-safe imports.
- This folder is Codex-mandated for audit traceability and modularity enforcement.

Ownership: Cursor (Codex v6.1.4, Phase 2.8.8)
